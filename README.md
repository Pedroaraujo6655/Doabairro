# DoaBairro

Página inicial de um projeto de mapeamento de doações locais. A proposta é aproximar moradores de ONGs e iniciativas comunitárias que precisam de alimentos, roupas e outros suprimentos.

## Como visualizar

Abra `index.html` em um navegador. Não é necessário instalar dependências ou iniciar um servidor.

## Arquivos

- `index.html`: página inicial com apresentação e exemplos de pedidos de ajuda.
- `style.css`: estilos responsivos da página.

Os pedidos exibidos são exemplos estáticos. A busca e os links para páginas adicionais ainda não têm funcionalidade implementada.
